# Security Policy

## Supported version
Only the latest `main` release is supported while AuditCompliance.cloud is pre-1.0.

## Reporting
Do not open public issues containing vulnerabilities, credentials, tenant data, or evidence artifacts. Use GitHub private vulnerability reporting when enabled for this repository, or the verified security contact published by AuditCompliance.cloud.

## Security boundaries
The current public foundation does **not** yet claim production-ready multi-tenant authentication, RBAC, evidence storage, or audit isolation. Those capabilities remain release blockers until implemented and tested.

## Disclosure principles
- Never publish secrets or customer evidence.
- Never represent readiness software as an independent audit opinion.
- Never claim certification without verified evidence.
